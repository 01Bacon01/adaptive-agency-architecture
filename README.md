## Core Axiom

Every adaptive system recursively constructs itself through four operations:

```python
while alive:

    observe()

    imagine()

    choose()

    become()
```

Observation updates the system's world model.

Imagination generates adjacent possible trajectories.

Choice selects among value-aligned possibilities.

Becoming transforms the system into its next state.

Learning is the accumulated history of repeated becoming.

Agency is the sustained capacity to recursively repeat this process while preserving the ability to revise future trajectories.

---

## Motivation

Adaptive Agency Architecture (AAA) is an attempt to define a minimal ontology for adaptive systems.

Rather than optimizing for a fixed objective, AAA models adaptive systems as continuously generating, evaluating, selecting, and realizing value-aligned future possibilities.

The same ontology is intended to describe multiple scales of adaptive behavior, including:

* Individuals
* Organizations
* Institutions
* Cities
* Governments
* Artificial Agents
